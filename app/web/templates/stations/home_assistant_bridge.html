Conecteaza Home Assistant

  1. Instaleaza integrarea EMS Home Assistant din repository-ul HACS personal.
  2. Genereaza codul de mai jos. Un cod nou revoca orice conexiune anterioara si sterge contextul ei.
  3. In Home Assistant → Dispozitive si servicii → Adauga integrare → EMS Home Assistant, introdu adresa HTTPS a EMS si codul.
  4. Confirma statia, alege senzorii, acorda consimtamantul si testeaza sincronizarea.

Confidentialitate si provenienta

Se importa exclusiv senzorii selectati. Ocuparea agregata necesita acord separat. Nu se importa persoane, camere, incuietori, alarme sau localizare. Nu sunt permise comenzi fizice.

Contextul Home Assistant ramane separat de contorul Deye. Valorile lipsa nu devin zero. Se pastreaza ultima valoare pe entitate, stearsa dupa 24 de ore (curatare orara); dupa expirarea pragului de prospetime valoarea este ascunsa imediat. Deconectarea sterge imediat contextul si credentialele.

Insights si notificarile bazate pe acest context sunt opt-in; procesarea lor in aplicatia mobila este o integrare separata.
